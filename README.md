# Robotic Arm Design 

A multi-component robotic arm and gripper system designed and assembled in **SolidWorks**. The project focused on 3D CAD modelling, mechanical assemblies, component interaction, and articulated motion.

## Project Overview 

The robotic arm consists of **11 individually designed components** that were modelled and combined into a complete mechanical assembly.

The design includes:
- Rotating base and support structure
- Multiple articulated arm links
- Servo motor components
- Mechanical gripper
- Gripper connecting links and joints
- Gear mechanisms

## Tools & Skills

- SolidWorks
- 3D CAD Modelling
- Parametric Design
- Assembly Modelling
- Mechanical Mates & Constraints
- Mechanical Linkages
- Design for Assembly

## Design Process

Individual components were created using SolidWorks features including:

- Extruded Boss/Base
- Extruded Cut
- Fillets
- Patterns
- Mirrored Geometry
- Reference Geometry
- Parametric Sketches

The components were then integrated into a complete assembly using **mates and mechanical constraints** to maintain proper alignment and enable articulated movement.
